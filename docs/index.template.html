⛴ claude-ferry

Start in Claude Chat and finish in Claude Code, or go the other way. Your chat comes across as real session history, not a wall of pasted text.

⛴ Ferry ← drag this to your bookmarks bar (on desktop)

How it works

Chat → Code

  1. Open a chat on claude.ai and click ⛴ Ferry.
  2. In your project folder, run: 
    npx github:patrickballard/claude-ferry in

Claude Code opens with the whole chat as its history, including the full source of every artifact. Ask it to “build what we discussed”.

Code → Chat

  1. In the folder where you used Claude Code, run: 
    npx github:patrickballard/claude-ferry out
  2. Pick a session. It's copied as clean markdown, so you can paste it into a new chat.

Add --tools to include one-line summaries of tool calls and --last 5 to keep only the last five exchanges.

Also

  • No bookmarklet? Export your data from claude.ai (Settings → Privacy) and run npx github:patrickballard/claude-ferry in conversations.json to choose any chat.
  • Branches: if you edited or retried messages, only the branch you're currently looking at is copied.
  • Private: the bookmarklet reads the chat from claude.ai with your own login and copies it to your clipboard. The CLI writes one file to ~/.claude/projects. Nothing is sent anywhere else.
